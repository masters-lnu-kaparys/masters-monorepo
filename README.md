# Моніторинг зайнятості паркомісць

Прототип системи моніторингу паркомісць і дослідження адаптивного планування вимірювань. Вузол на ESP32 з датчиком HC-SR04 надсилає телеметрію через Azure IoT Hub. Сервер зберігає вимірювання в SQL Server і оновлює карту у вебзастосунку через SignalR.

## Запуск і налаштування

- [Вебзастосунок і демонстрація адаптивних вимірювань](frontend/README.md)
- [Сервер, база даних і передавання телеметрії](backend/README.md)
- [Підключення датчика та збірка прошивки ESP32](sketch_dec15a/README.md)

Сторінка `/measurements` відтворює три фрагменти історії зайнятості й показує, як вибір паузи впливає на кількість вимірювань та актуальність карти. Для її запуску достатньо клієнтського застосунку.

## Результати дослідження

Запропонований метод оцінено на відкладених записах 867 паркомісць Мельбурна. Порівняння зі щохвилинним розкладом охоплює кількість вимірювань, час помилкового відображення стану та пропущені вільні епізоди. [Підсумок експерименту](docs/research/adaptive-sampling/phase4-display-report.md)

Репозиторій містить код симуляції, зафіксовані параметри, результати та графіки. Підготовка починається з відкритого набору даних міста Мельбурн. [Інструкція з відтворення та джерело даних](docs/delivery/README.md)
