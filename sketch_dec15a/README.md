# Прошивка ESP32 для моніторингу паркомісця

Прошивку зібрано з Arduino CLI 1.5.1 для `esp32:esp32:esp32`, пакета Arduino-ESP32 2.0.17 і бібліотеки PubSubClient 2.8.0.

## Налаштування та збірка

Підключіть TRIG до GPIO5, а ECHO до GPIO18. Для ECHO датчика HC-SR04 потрібне узгодження з рівнем 3,3 В ESP32. Координати вузла задаються в його налаштуваннях.

Скопіюйте `device_secrets.example.h` у `device_secrets.h` у цій папці й заповніть параметри мережі, IoT Hub і зареєстрованого пристрою. Файл із параметрами залишається локальним.

Команди виконуються з кореня репозиторію.

```powershell
arduino-cli core update-index --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
arduino-cli core install esp32:esp32@2.0.17 --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
arduino-cli lib install PubSubClient@2.8.0
arduino-cli compile --fqbn esp32:esp32:esp32 --build-property 'compiler.cpp.extra_flags=-DSAS_REFRESH_TEST -DOCCUPANCY_STATE_TEST' sketch_dec15a
```

Прапорці додають перевірки строку дії токена SAS та граничних випадків визначення зайнятості.

## Вимірювання й телеметрія

Вузол усереднює коректні відстані від 2 до 400 см. За стандартних порогів відстань менша за 40 см означає «зайнято», а більша за 55 см означає «вільно». Між порогами, включно з їхніми межами, зберігається попередній стан.

Після запуску стан невизначений до першого коректного виміру поза межами 40–55 см. Телеметрію надсилають після визначення стану за наявності коректної відстані. До визначення стану команда `measureNow` може повернути коректну відстань і `occupied: null`. Сервер позначає попередні покази як застарілі після налаштованого строку.

Прошивка виконує вимірювання з фіксованим циклом близько п’яти секунд. Для лабораторної демонстрації використайте відбивач у робочому діапазоні датчика по обидва боки порогів. Адаптивний розклад відтворюється окремо у вебзастосунку. [Запуск демонстрації](../frontend/README.md)
