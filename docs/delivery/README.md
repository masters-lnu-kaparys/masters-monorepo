# Матеріали для передавання

Репозиторій містить код застосунку, браузерну демонстрацію і зафіксовані
результати експерименту. Запустіть із кореня репозиторію після встановлення
дослідницьких залежностей.

```powershell
python -m pip install -r research/parking_sampling/requirements.txt
python tools/verify_research_delivery.py
```

Повний набір підготовлених даних та інструкція `README-DELIVERY.md` містяться в
окремому архіві `masters_ready_2026-11-21.zip`. PDF для подання експортується з
чинної редакції магістерської роботи.

- [Запуск браузерної демонстрації](../../frontend/README.md)
- [Протокол експерименту](../research/adaptive-sampling/phase4-display-protocol.md)
- [Звіт про результати](../research/adaptive-sampling/phase4-display-report.md)

Демонстраційні фрагменти й дослідницькі результати отримано з відкритих записів
[On-street Car Parking Sensor Data - 2019](https://data.melbourne.vic.gov.au/explore/dataset/on-street-car-parking-sensor-data-2019/information/)
