# Локальна оцінка ризику й калібрування розкладу

Поточний практичний результат: [звіт із графіками](../../docs/research/adaptive-sampling/phase3-local-risk-report.md), [метод L.1-L.6](../../docs/research/adaptive-sampling/phase3-local-risk-method.md), [джерела](../../docs/research/adaptive-sampling/phase3-local-risk-sources.md). Попередні невдалі кандидати збережено. Ці програми не змінюють API, прошивку або головний текст магістерської.

Команди з кореня репозиторію, у Python із залежностями `requirements.txt`:

```powershell
python research/parking_sampling/run_local_risk.py
python research/parking_sampling/local_risk_bay_control.py
python research/parking_sampling/local_risk_calibration_v3.py
python research/parking_sampling/local_risk_wide_control.py
python research/parking_sampling/local_risk_full_model_control.py
python research/parking_sampling/local_risk_union_control.py
python research/parking_sampling/audit_local_risk.py
python research/parking_sampling/report_local_risk.py
python research/parking_sampling/verify_local_risk.py
```

Перший запуск навчається на січні-червні дозволених відомих місць. Вибір параметрів використовує первісні групи 256/128; наступні перевірки - вже відомі групи 256/512 липня-вересня. Це розроблення після попередніх експериментів, а не незалежне остаточне підтвердження. Історії зарезервованих місць для цього методу не відкриваються. Файл `phase4-display-protocol-draft.json` є окремою неактивованою чернеткою; він не дозволяє читати остаточний тест.

Результати містяться у `.codex-work/parking-local-risk-20261025/`. План і хеші коду зберігаються перед навчанням, моделі й вибір - перед їхніми перевірочними запусками. Не перезаписувати ці артефакти після змін коду: нове дослідження потребує нової версії. Технічна версія `local_risk_calibration.py` зупинилася до вибору й перевірок через округлення спільної експозиції; її папку `calibration-v2` збережено. Версія 3 виправляє тільки точне подання цієї інваріанти.

`calibrated_schedule.py` виконує вже навчене рішення за BayId та оплаченими спостереженнями. JSON містить три повні таблиці для кожного навченого місця й спільний резервний варіант. Одну таблицю обирає стабільний хеш BayId до спостережень, без змішування дій у кожному циклі. Основне зерно 20261025; усі десять наперед визначених зерен також показані. Очікувані лічильники суміші та реалізований вибір таблиць подано окремо.

`frozen_local_priors.py` дозволяє додати локальну навчальну історію нових місць, зберігаючи заморожені спільні оцінки. Поточна квитанція перевіряє точну рівність на наявних 1063 місцях; зарезервованих історій вона не читає.

Основний результат: менше вимірювань і менші обидва часи помилкового показу карти. Ціна - ненульовий M60, тобто деякі вільні епізоди від хвилини не мають нового виміру всередині. Початковий критерій нульового M60 не виконано. Приблизно третина-дві п'ятих окремих місць мають більший особистий F або O. Економію батареї фізичного вузла не виміряно.

Сильні контролі мають ту саму максимальну паузу 300 секунд. Зафіксовані ваги конкурентів відокремлено від ретроспективних меж: останні підбираються за перевірочними наслідками, тому є лише оптимістичними довідковими порівняннями. Старі програми `verify_*` змінювали статус свого етапу; для поточного стану використовувати саме `verify_local_risk.py`, який зберігає історичні знімки та всі попередні маніфести.
