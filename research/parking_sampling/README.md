# Остаточний експеримент

Код відтворює зафіксовані розклади вимірювань на записах зайнятості 867 паркомісць. Він звіряє рішення для кожного місця, підсумкові показники та довірчі інтервали.

- `download_source.py` завантажує відкритий набір Мельбурна.
- `prepare_data.py` перевіряє часові записи, формує відомі вікна та поділяє дані.
- `replay_final.py` повторює оцінювання за опублікованими параметрами з `results/`.
- `test_*.py` перевіряють підготовку даних, оцінку ризику, симуляцію та статистичний аналіз.
