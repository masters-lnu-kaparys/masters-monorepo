# Прошивка лабораторного прототипу

Перевірена збірка: Arduino CLI 1.5.1, плата `esp32:esp32:esp32`, Arduino-ESP32
2.0.17, PubSubClient 2.8.0. Компіляція не є перевіркою роботи на автомобілі.

1. Скопіювати `device_secrets.example.h` у `device_secrets.h` у цій папці.
2. Заповнити власні параметри мережі, IoT Hub та зареєстрованого пристрою.
   Локальний файл не входить до Git і комплекту передавання.
3. Установити підтримку плат і бібліотеку, зібрати:

```powershell
arduino-cli core update-index --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
arduino-cli core install esp32:esp32@2.0.17 --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
arduino-cli lib install PubSubClient@2.8.0
arduino-cli compile --fqbn esp32:esp32:esp32 --build-property 'compiler.cpp.extra_flags=-DSAS_REFRESH_TEST -DOCCUPANCY_STATE_TEST' sketch_dec15a
```

`SAS_REFRESH_TEST` додає п'ять перевірок під час компіляції: відсутній токен,
звичайний строк, межа завчасного оновлення, момент завершення й уже прострочений
токен. Прошивка перестворює MQTT-з'єднання з новим SAS, а не намагається змінити
пароль у чинному з'єднанні. Автоматичного прошивання під час перевірок немає.

TRIG - GPIO5, ECHO - GPIO18. ECHO HC-SR04 потребує узгодження з рівнем 3,3 В
ESP32. Координати в коді задаються вручну; GPS-модуля немає. Пороги 40/55 см
демонструють гістерезис і не є універсальним калібруванням для всіх авто.

Враховуються коректні відстані 2-400 см. Після запуску перше коректне середнє
нижче 40 см або вище 55 см встановлює стан за стандартними порогами. Між
порогами, включно з їхніми межами, зберігається поточний стан.
`OCCUPANCY_STATE_TEST` перевіряє обидві межі, початковий невизначений стан і
збереження вже відомого стану.

Телеметрія з’являється після визначення зайнятості. Якщо команда `measureNow`
отримала коректну відстань між порогами до визначення стану, відповідь містить
відстань і `occupied: null`. Без жодної коректної відстані за цикл нового
повідомлення немає. API після налаштованого строку позначає попередні дані як
застарілі та виключає місце з підрахунку доступності.

Для відтворення лабораторної демонстрації потрібен відбивач у вимірюваному
діапазоні для обох порогових положень. За відкритого монтажу знизу вгору вільне
місце може не мати такого відбивача: ця геометрія потребує окремого вибору
режиму сенсора й перевірки. Польова класифікація авто, захист від погоди,
споживання та ресурс батареї в роботі не вимірювалися.

Науковий планувальник поки виконується окремо на записаній історії та в
браузерній демонстрації. Ця прошивка використовує фіксований цикл близько 5 с.
