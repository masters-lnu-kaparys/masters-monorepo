# Адаптивне планування вимірювань зайнятості

Розклад визначає паузу до наступної перевірки за виміряним станом і
доступною історією паркомісця. Метод оцінено на відкладених записах
867 місць із відкритого набору міста Мельбурн за 2019 рік.

На вікнах від семи діб запропонований метод потребував на **18,13%** менше
вимірювань, ніж щохвилинний розклад. Час помилкового відображення «вільно»
зменшився на **13,91%**, «зайнято» – на **13,30%**. Частка вільних епізодів
від хвилини, які залишилися без вимірювання, становила **0,202%**.
Вікна від доби використовують ті самі місця для перевірки чутливості.
