# Історичний контроль C0

`C0-archived-pilot.npz` - точна копія `risk-table.npz` із пошукового аудиту 18.10.2026. Навчання виконувалося на січні-червні для початкових 25 місць. Таблицю не перенавчали й не виправляли заднім числом.

Це історичний контроль, а не чиста перевірка однієї зміни методу: нові правила використовують інший обсяг навчання, окрему помилку «зайнято», профіль тривалостей і виправлену граничну мітку. У старій мітці кінець звільнення перевірявся як `< наступний вимір`; у новій правильно `<= наступний вимір` для напіввідкритих інтервалів.

Походження пошукових даних: [phase1-evidence.json](../../../docs/research/adaptive-sampling/phase1-evidence.json). SHA-256 цієї копії, навчальних моделей і правил зафіксовано в [phase3-method-lock.json](../../../docs/research/adaptive-sampling/phase3-method-lock.json). Контроль не є результатом незалежного остаточного тесту.
