# Вебзастосунок для моніторингу паркомісць

Для розроблення потрібен Node.js 22.13 або новіший. Команди виконуються з папки `frontend`.

```powershell
npm ci
npm run dev
```

## Демонстрація адаптивних вимірювань

Відкрийте `/measurements` на локальній адресі Vite. У меню карти це пункт «Вимірювання». Сторінка самостійно відтворює три фрагменти відкритих сенсорних записів Мельбурна за 2019 рік.

- Оберіть паркомісце й запустіть відтворення або перейдіть до наступного виміру.
- На графіку порівняйте записаний стан із показами адаптивного та щохвилинного розкладів.
- Відкрийте пояснення паузи, щоб побачити оцінки помилки й витрат для кожного варіанта.
- Перегляньте журнал вимірювань або збережіть його у форматі CSV.

Для демонстрації використовуються зафіксовані дані в `public/data/sampling-demo.json`. Контрольні траси в `tests/fixtures/sampling-demo-golden.json` звіряють рішення браузера з результатами Python. [Підсумок експерименту на 867 паркомісцях](../docs/research/adaptive-sampling/phase4-display-report.md)

## Карта й робота з пристроями

Для повної роботи карти підніміть API та фонову службу. Скопіюйте `.env.example` у `.env.local` і вкажіть адресу API та параметри входу. [Налаштування сервера](../backend/README.md)
